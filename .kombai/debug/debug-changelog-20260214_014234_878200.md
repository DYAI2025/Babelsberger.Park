# Debug Changelog - Hero-Überschriften Korrektur
**Session ID:** 20260214_014234_878200  
**Datum:** 2026-02-14  
**Problem:** Überschriften liegen direkt auf Hero-Bildern, sind schwer lesbar, zu klein, nicht barrierefrei

## Problemanalyse

**Ist-Zustand:**
```html
<div class="hero" style="background-image: url('...')">
  <h1>Titel <span>Untertitel</span></h1>
</div>
```

**Probleme:**
- Text liegt direkt auf Bild (schlechte Lesbarkeit)
- Schriftgröße zu klein auf mobilen Geräten
- Abhängig von Bildfarben (dunkle Bilder → dunkler Text kaum lesbar)
- Nicht barrierefrei

**Soll-Zustand:**
```html
<div class="hero">
  <img src="..." alt="..." width="1200" height="675" loading="eager">
</div>

<main>
  <header class="content-header">
    <h1>Titel</h1>
    <p class="subtitle">Untertitel</p>
  </header>
  <!-- Rest des Contents -->
</main>
```
