## Context

This project uses a centralized ad configuration in `park-babelsberg/assets/ad-config.js`. All 60+ HTML pages reference this config via placeholder slot names (BABELSB_TOP_1, etc.) that get resolved to real numeric slot IDs at runtime. The AdSense publisher ID is `ca-pub-1712273263687132`.

## Your Task

When the user pastes AdSense ad code snippets, extract the slot ID and name, then map it into `ad-config.js`.

### Steps

1. **Parse the snippet** — Extract from the pasted `<ins class="adsbygoogle">`:
   - `data-ad-slot` → numeric slot ID (e.g. `7082205943`)
   - HTML comment above → slot name (e.g. `BB_desktop`, `bb_hoch1`)
   - `data-ad-format` → format hint (auto, horizontal, rectangle, vertical)

2. **Skip AMP code** — If `<amp-ad>` tags are included, ignore them. This site is NOT AMP.

3. **Read current ad-config.js** — Check existing AD_SLOTS entries and which slot IDs are already mapped.

4. **Distribute to positions** — Map new slot IDs to appropriate AD_SLOTS positions based on format:

   | Format hint | Best positions |
   |---|---|
   | horizontal/desktop/breit | TOP_HORIZONTAL, PLANEN_AUTO |
   | vertical/hoch | MIDDLE_HORIZONTAL, FAQ_AUTO, IN_ARTICLE |
   | rectangle/quadrat | PARKS_AUTO, STICKY_MOBILE, INFEED |
   | auto (generic) | Distribute evenly across unfilled positions |

5. **Update ad-config.js** — Edit the AD_SLOTS object with the new slot IDs and descriptive comments.

6. **Report** — Show a table of slot ID → position mappings.

### Guardrails

- Never duplicate the `<script async src="...adsbygoogle.js">` tag — it's already in every page's `<head>`
- Never add inline `(adsbygoogle = ...).push({})` calls — `ad-config.js` handles initialization
- AMP code (`<amp-ad>`, `amp-ad-0.1.js`) must always be ignored
- If multiple snippets are pasted at once, handle all of them
- Vary slot IDs across positions for better AdSense reporting granularity
