## Context

This project is a static bilingual (DE/EN) park website at `park.babelsberger.info`. Blog articles live in `park-babelsberg/blog/` and must follow strict SEO requirements for Google Discover eligibility and AdSense RPM optimization.

## Your Task

Create a new blog article with all required SEO elements. The user will provide the topic/title.

### Steps

1. **Choose template**: Read an existing blog article (e.g. `park-babelsberg/blog/geheime-orte-park-babelsberg.html`) as reference template

2. **Create HTML file** in `park-babelsberg/blog/` with:
   - `<meta name="robots" content="max-image-preview:large, max-snippet:-1, max-video-preview:-1">` (Google Discover)
   - Canonical URL: `https://park.babelsberger.info/blog/[slug]/`
   - Full Open Graph tags: `og:type=article`, `og:url`, `og:title`, `og:description`, `og:image` (with dimensions 1200x630), `og:locale=de_DE`, `og:site_name=Potsdam Parks`
   - `article:published_time`, `article:modified_time`, `article:section`
   - Twitter Card: `summary_large_image`
   - BlogPosting Schema.org JSON-LD (headline, description, image, datePublished, dateModified, author, publisher with logo, articleSection, inLanguage)
   - GA4 `G-K409QD2YSJ` + AdSense `pub-1712273263687132` (loaded after cookie consent)
   - Dark mode support via existing `style.css` + `blog.css`
   - i18n attributes (`data-i18n`) on translatable elements

3. **Add route** in `vercel.json` (before catch-all route):
   ```json
   { "source": "/blog/[slug]/", "destination": "/park-babelsberg/blog/[slug].html" }
   ```

4. **Add to sitemap.xml**:
   ```xml
   <url>
     <loc>https://park.babelsberger.info/blog/[slug]/</loc>
     <lastmod>[today YYYY-MM-DD]</lastmod>
     <changefreq>monthly</changefreq>
     <priority>0.7</priority>
   </url>
   ```

5. **Add translations** to both `park-babelsberg/assets/translations/de.json` and `en.json`

6. **Add internal cross-links**:
   - "Den Park entdecken" CTA in the article linking to 3 relevant attraction pages
   - Add article card to blog index (`park-babelsberg/blog/index.html`)
   - Optionally add "Aus unserem Magazin" card on 1-2 related attraction pages

7. **Verify checklist**:
   - [ ] HTML file created with all meta tags
   - [ ] Schema.org JSON-LD present and valid
   - [ ] Route added to vercel.json
   - [ ] Sitemap entry added
   - [ ] Translations added (DE + EN)
   - [ ] Blog index updated
   - [ ] Internal cross-links added
   - [ ] `data-date` attribute set on `<main>`

### Guardrails

- Always use WebP images (hero: 1600x900, OG: 1200x630)
- System fonts only (no Google Fonts) — DSGVO compliance
- Date must be synchronized in: `<main data-date>`, "Stand:" text, sitemap `<lastmod>`
- Default language is German, English is translation
- AdSense/GA4 must only load after cookie consent
- Blog CSS is in `park-babelsberg/assets/blog.css` (not style.css)
